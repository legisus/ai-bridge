# Privacy Policy — AI Browser Bridge

_Last updated: 2026-09-07. Applies to the AI Browser Bridge Chrome extension and the
bridge server in this repository._

## Summary

AI Browser Bridge collects **no personal data, no browsing data, and no analytics**.
It sends nothing to the developer or to any third party. The extension talks to
exactly one endpoint: a server on `127.0.0.1` (your own computer) that you install
and run yourself.

## What the extension does

The extension has a single purpose: let a program running on your own computer
(for example an AI coding agent in your terminal) control tabs in your browser
through a local relay. Every action the extension performs is one that the local
program requested: open or close a tab, read or change page content, click, type,
scroll, take a screenshot, print a page to PDF, or download a file.

## Data handling

| Data | Where it goes | Retained? |
|---|---|---|
| Page content, screenshots, PDFs, results of scripts | Returned over the local socket to the program that asked | Not by the extension. The local server does not store results. |
| Command log (command name and parameters) | `~/.ai-browser-bridge/bridge.log` on your computer, written by the local server | Until you delete the file. Never transmitted. |
| Auth token | Generated by the local server, stored in `~/.ai-browser-bridge/token` (mode 600) and in the extension's `chrome.storage.local`; handed to the extension either by you (options page) or by the native messaging host over Chrome's stdio channel | Until you remove the extension or delete the file. |
| Settings (port, host allowlist, indicator, idle-detach) | `chrome.storage.local` | Until you remove the extension. |

The extension never makes a network request to any host other than `127.0.0.1`. It
contains no analytics, crash reporting, telemetry, advertising, or remote
configuration.

## Permissions and why they are needed

- **`tabs`** — list, open, activate, and close tabs on request.
- **`scripting`** — run the extension's own bundled functions in a page for
  clicks, typing, scrolling, waiting for elements, and the activity indicator.
- **`userScripts`** — run a code snippet supplied by the local program in a page
  (the `eval` command). This is Chrome's designated API for user-supplied code;
  it works only after you turn on **Allow User Scripts** for the extension.
- **`debugger`** — on explicit request per command (`--debugger`), attach Chrome's
  DevTools protocol to a tab for trusted input, print-to-PDF, and background-tab
  screenshots. Chrome shows its "is debugging this browser" banner while attached.
- **`downloads`** — save a file with your existing cookies when asked.
- **`storage`** — keep the token and settings.
- **`alarms`** — reconnect to the local server and release idle debugger sessions.
- **`nativeMessaging`** — ask a small helper program on your computer (the native
  messaging host you register yourself) for the token and port, and let it start
  the local server. The helper answers only this extension's ID and sends nothing
  anywhere. If it is not registered, the extension simply waits for a token to be
  entered in its options.
- **Host permission `<all_urls>`** — the local program may need to act on any site
  you choose. You can restrict this to specific domains with the **host allowlist**
  in the extension's options; the extension refuses commands on other domains.

## Your controls

- **Host allowlist** — limit the extension to domains you name.
- **Token** — nothing can command the extension without the token from your own
  machine. Regenerate it by deleting `~/.ai-browser-bridge/token` and restarting
  the server.
- **Debugger approval** — the DevTools route is off unless you pass `--debugger`,
  set `AI_BRIDGE_DEBUGGER=1`, or answer the interactive prompt.
- **Activity indicator** — tabs under control show a colored frame and favicon
  badge (can be turned off in options).
- **Uninstall** — remove the extension in `chrome://extensions`, stop the server,
  and delete `~/.ai-browser-bridge/`. Nothing else is left behind.

## Children

The extension is a developer tool and is not directed at children.
